# 📚 Personal Reading Tracker

Aplikasi penjejak membaca buku personal yang ringan, interaktif, dan mudah digunakan. Dibuat untuk membantu melacak progres membaca, mencatat ulasan, dan membangun kebiasaan membaca yang konsisten.

🌐 **Live Demo:** [Klik di sini untuk membuka aplikasi](https://USERNAME.github.io/REPOSITORY-NAME/) *(Ubah tautan ini setelah deploy)*

---

## 🚀 Fitur Utama

- 📖 **Manajemen Koleksi:** Simpan daftar buku berdasarkan status (*Want to Read*, *Currently Reading*, *Finished*, *DNF*).
- 📊 **Progress Tracker:** Pantau persentase halaman yang sudah dibaca secara visual.
- ⏱️ **Reading Timer:** Timer bawaan untuk mencatat durasi setiap sesi membaca.
- 📝 **Jurnal & Quotes:** Catat kutipan favorit dan ulasan buku favoritmu.
- 🔥 **Gamifikasi & Statistik:** Target tahunan, *streak tracker*, dan statistik membaca harian.
- 💾 **Data Aman:** Semua data tersimpan otomatis di browser (*LocalStorage*) tanpa perlu login.
